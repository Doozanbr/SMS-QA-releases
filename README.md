# SMS QA releases

SMS QA update packages for clinic PCs. No clinic data.

## Download

**[Download the latest version](https://github.com/Doozanbr/SMS-QA-releases/releases/latest)**, then under Assets click the `SMS-QA-x.y.z.zip` file.

1. Unzip it to a folder on the PC (for example `C:\SMS QA`).
2. Run `MonthlyQa.exe`.

After that, SMS QA checks for updates itself and offers new versions when they're published, so you don't need to come back here.

All versions: [Releases](https://github.com/Doozanbr/SMS-QA-releases/releases).
